# 🎬 Movie Analytics Dashboard

# 📌 Overview
This project is an interactive Power BI dashboard created using a movie credits dataset.

# 🛠 Tools Used
- Power BI
- CSV Dataset
- Data Visualization

## 📊 Features
- KPI Cards
- Role Distribution Analysis
- Top 10 Actors
- Interactive Filtering
- Actor Movie Count Table

## 📈 Insights
- Actor roles dominate the dataset
- Dashboard supports dynamic filtering
- Interactive analytics using Power BI
